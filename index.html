Conception & Modélisation

Conception et Programmation Objet

Durée : 3 jours · Niveau : Fondamental

Comprendre l'intérêt et les possibilités offertes par le développement objet par rapport à une approche fonctionnelle. Les participants apprennent à concevoir un modèle de classes pertinent, à respecter les bonnes pratiques de conception (Design Patterns) et à traduire leur travail sous forme de diagramme de classes UML, avec une ouverture sur l'apport de l'IA dans la conception objet.

  • Comprendre les principes et spécificités de la conception Objet
  • Passer d'une approche fonctionnelle à une approche Objet
  • Concevoir un modèle de classes pour ses applications
  • Mettre en œuvre les concepts objets à travers un projet fil rouge

UML 2 — Analyse et Conception

Durée : 4 jours · Niveau : Fondamental

Le langage de modélisation unifié UML propose un langage visuel commun et normalisé pour décrire un système logiciel, principalement en conception orientée objet. Cette formation permet de comprendre et d'utiliser les diagrammes UML les plus pertinents à toutes les étapes d'un projet de développement.

  • Comprendre le rôle des différents modèles UML selon les phases d'un projet
  • Exprimer un besoin fonctionnel sous forme de diagramme UML
  • Mettre en œuvre la modélisation UML sur toutes les étapes d'un projet
  • Maîtriser les bonnes pratiques de conception logicielle

Bases de données & SQL

Bases de Données Relationnelles : Conception et Modélisation

Durée : 4 jours · Niveau : Fondamental

Une synthèse complète des connaissances indispensables en matière de bases de données, du processus de conception à son utilisation effective, avec de nombreux travaux pratiques permettant de manipuler chacun des concepts importants.

  • Comprendre les forces et faiblesses d'une base de données relationnelle
  • Suivre le processus de conception logique et physique d'une base
  • Trouver le compromis entre normalisation et non-normalisation
  • Maîtriser les manipulations SQL de base et leur fonctionnement interne

Maîtriser le SQL

Durée : 5 jours · Niveau : Fondamental

Le langage SQL est incontournable pour interroger et mettre à jour les bases de données. Cette formation explique la structure générale d'un SGBDR et la philosophie du langage afin d'écrire des requêtes simples ou complexes avec naturel, y compris jointures externes et sous-requêtes corrélées.

  • Comprendre le schéma d'une base et des tables
  • Écrire des requêtes SQL pour extraire et mettre à jour les données
  • Maîtriser les jointures et leurs variantes ainsi que les requêtes ensemblistes
  • Écrire des requêtes SQL complexes (sous-requêtes corrélées, etc.)

Java

Java, les Fondamentaux

Durée : 5 jours · Niveau : Fondamental

Le langage Java est au cœur des applications d'entreprise. Cette formation fait acquérir de solides bases sur le langage et initie progressivement aux API cœurs incontournables (collections, I/O, JDBC, Streams) à travers une application fil rouge.

  • Connaître les concepts de base du langage Java et sa syntaxe
  • Utiliser les bibliothèques et API (collections, I/O, JDBC, Streams…)
  • Comprendre les concepts de la programmation orientée objet en Java
  • Créer une application en Java et gérer les erreurs de code

Java Avancé, Perfectionnement

Durée : 4 jours · Niveau : Avancé

Permet d'approfondir ses connaissances du langage pour intégrer directement une équipe projet : fonctionnement de la JVM, applications multi-threadées, manipulation de données (JDBC, NIO.2, Streams) et industrialisation avec Gradle ou Maven.

  • Maîtriser les aspects avancés du langage Java
  • Comprendre le modèle de sécurité et le chargement des classes Java
  • Programmer en Java dans le contexte des bases de données relationnelles
  • Savoir tester, déboguer et optimiser ses applications

Java 8 : Nouveautés de Java 8

Durée : 2 jours · Niveau : Fondamental

Java 8 a apporté des améliorations significatives au langage. Cette formation présente les expressions lambda, la programmation fonctionnelle et les nouvelles API introduites par cette version majeure.

  • S'initier aux principes de la programmation fonctionnelle
  • Maîtriser les expressions lambda et les références de méthodes
  • Mettre en œuvre les Streams pour manipuler des flux de données
  • Comprendre la nouvelle API Date&Time (JSR 310)

Nouveautés de Java 11 et Java 17

Durée : 2 jours · Niveau : Fondamental

Java 11 et Java 17 sont des versions LTS (Long Term Support) utilisables en production. Cette formation présente, version après version, les nouveautés apportées jusqu'à ces dernières versions LTS (modularité, records, classes scellées, etc.).

  • Connaître les nouveautés apportées aux dernières versions LTS de Java
  • Mettre en pratique les nouveautés les plus significatives
  • Comprendre l'impact de la modularité sur les applications
  • Appréhender les records et classes scellées de Java 17

Le Framework JUnit

Durée : 2 jours · Niveau : Intermédiaire

JUnit est le standard de facto pour l'implémentation des tests unitaires et d'intégration des applications Java. Cette formation très pratique permet de maîtriser le framework et d'adopter une méthodologie Test Driven Development.

  • Comprendre l'intérêt et les limites des tests unitaires
  • Utiliser JUnit avec ses programmes Java
  • Mettre en œuvre des tests d'intégration
  • Utiliser JUnit dans un contexte d'intégration continue (CI)

JavaFX : Développer des Applications Graphiques Riches

Durée : 3 jours · Niveau : Intermédiaire

JavaFX est le successeur officiel de Swing et permet de développer des clients riches en simplifiant leur développement grâce au langage FXML et à l'outil SceneBuilder.

  • Utiliser les outils de base et les composants d'interface utilisateur
  • Intégrer JavaFX et Swing
  • Mettre en œuvre les threads afin d'améliorer la réactivité de l'IHM
  • Créer des interfaces avec FXML et SceneBuilder

Qualité & Outils

Optimiser la Qualité du Développement avec Test Driven Development

Durée : 3 jours · Niveau : Fondamental

Le Test Driven Development (TDD) est une technique de programmation simple, élégante et efficace, basée sur un cycle court : écrire un test, le faire passer, refactorer le code. Elle combine la sécurité des tests automatisés à l'avantage d'une conception modulaire et lisible.

  • Connaître les avantages du TDD par rapport aux autres techniques
  • Développer une application simple avec TDD
  • Expliquer et illustrer les principes de cette démarche
  • Appliquer des techniques spécifiques de TDD sur un projet existant

GIT : Gestion des Sources avec GIT

Durée : 2 jours · Niveau : Fondamental

Git est un système de contrôle de versions distribué conçu pour traiter aussi bien de petits que de très gros projets, avec rapidité et efficacité. Cette formation permet de configurer et utiliser Git au quotidien et de choisir un workflow de collaboration adapté à son équipe.

  • Connaître le fonctionnement d'un système de contrôle de versions distribué
  • Créer et initialiser un dépôt Git
  • Connaître les workflows et rôles relatifs à la gestion des sources
  • Gérer et organiser les fichiers et les branches Git

Design UX/UI

Figma : Concevoir des Maquettes UX/UI

Durée : 2 jours · Niveau : Fondamental

Figma se distingue par la capacité de travailler en équipe sur des projets grâce à des modifications en temps réel via un navigateur web. Cette formation permet d'identifier et d'utiliser les différents outils proposés par Figma en toute autonomie.

  • Concevoir et modifier ses maquettes directement en ligne
  • Collaborer efficacement entre designers, développeurs et équipes produit
  • Créer des prototypes interactifs pour tester rapidement ses idées
  • Mettre en place un design system évolutif et cohérent

Figma Perfectionnement : Optimiser son Workflow

Durée : 2 jours · Niveau : Intermédiaire

Cette formation rend les participants autonomes dans la création, la structuration et l'optimisation d'un design system dans Figma : composants avancés, variants, variables, prototypes complexes et Dev Mode pour le partage avec les développeurs.

  • Exploiter les dernières nouveautés de Figma
  • Construire un design system optimisé avec collections et variables
  • Optimiser son workflow, du prototype au partage avec les développeurs
  • Intégrer les plugins IA pour gagner en productivité

Photoshop : Retouche d'Images et Objets

Durée : 3 jours · Niveau : Fondamental

Cette formation fournit les concepts et méthodes pour une utilisation efficace d'Adobe Photoshop au quotidien, avec une expérience pratique des techniques de base pour la retouche d'images.

  • Maîtriser les fonctions simples de Photoshop
  • Modifier la colorimétrie d'une image et créer des calques
  • Réaliser des retouches photo (transformations, déformations, tampon)

Langages C & C++

Programmation en C

Durée : 5 jours · Niveau : Intermédiaire

Le langage C reste très utilisé aujourd'hui, notamment dans l'embarqué (système dédié, IoT, drivers). Cette formation permet d'écrire des programmes robustes, portables et conformes à la norme ANSI, tout en donnant de bonnes bases en sécurité du développement.

  • Comprendre le fonctionnement de la programmation structurée
  • Maîtriser la syntaxe et les principales fonctions du langage C
  • Écrire un programme C modulaire, portable (ANSI) et maintenable
  • Maîtriser les mécanismes de gestion de la mémoire (pile, pointeurs, sécurité)

C++ : Programmation Objet en C++

Durée : 5 jours · Niveau : Intermédiaire

Le langage C++ a apporté au langage C la dimension objet tout en capitalisant sur ses performances (typage fort, surcharge de fonctions, programmation générique, STL). Cette formation permet de produire un code de qualité respectant les bonnes pratiques professionnelles.

  • Comprendre la syntaxe et les concepts fondamentaux du C++
  • Maîtriser les ajouts majeurs des normes C++ (dont C++ 11)
  • Appliquer les principes de la Conception Orientée Objet
  • Manipuler les fichiers et la mémoire de manière sécurisée

Culture Informatique

Panorama des Technologies Informatiques

Durée : 4 jours (4 modules d'1 jour) · Niveau : Fondamental

Un séminaire complet, actualisé, concret et accessible qui permet de dialoguer avec les experts de chaque domaine sans déléguer les échanges dès que le niveau technique s'élève, en abordant successivement le matériel et les systèmes d'exploitation, les réseaux/le web/la sécurité, le développement logiciel et les bases de données, puis le développement web et mobile.

  • Matériel et systèmes d'exploitation : décoder le vocabulaire informatique associé
  • Réseaux, Web et Sécurité : comprendre les concepts et technologies impliqués
  • Développement, bases de données et architecture des applications
  • Développement Web et mobile : Front-end, Back-end, API et responsive design

Intelligence Artificielle pour Développeurs

Développeurs, Booster ses Performances grâce à l'IA

Durée : 2 jours (14h) · Niveau : Intermédiaire

Cette formation montre comment intégrer efficacement des outils d'intelligence artificielle dans le quotidien d'un développeur : accélérer la production de code, fiabiliser les livrables générés par l'IA et appliquer des réflexes de cybersécurité adaptés à ces nouveaux usages.

  • Intégrer des outils d'IA dans son flux de travail de développement
  • Automatiser certaines tâches grâce à des assistants IA
  • Évaluer les risques liés à l'usage de l'IA générative en contexte de développement
  • Appliquer de bonnes pratiques de cybersécurité (données sensibles, confidentialité du code)

IA pour Développeurs : Code Assisté et Programmation Intelligente

Durée : 2 jours · Niveau : Intermédiaire

Cette formation initie les développeurs à la programmation assistée par IA : prise en main d'assistants de complétion de code, génération de tests et de documentation, revue critique des suggestions produites, et bonnes pratiques de formulation de prompts pour fiabiliser les résultats.

  • Comprendre le fonctionnement des assistants de code basés sur l'IA
  • Utiliser un assistant IA pour accélérer l'écriture, la complétion et la relecture de code
  • Formuler des prompts efficaces pour obtenir des suggestions pertinentes
  • Identifier les limites et les risques d'un usage non maîtrisé de ces outils
